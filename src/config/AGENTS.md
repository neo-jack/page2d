## 导航与个人资料配置

本目录维护2D主页的导航、个人信息和菜单，继承项目根AGENTS.md。

### Important files

- `menu.ts` — 外链菜单。
- `nav.ts` — 项目导航、分类与图标路径；分类顺序固定为 AI、提效、研究、其他。
- `profiles.ts` — 个人信息与头像。

### Implementation notes

- 生产页面入口为 `/`，资源仍使用Vite BASE_URL `/2D/`；资源路径与页面公开入口不要混淆。
- 修改后运行 `pnpm run build`，验证导航目标与hash页面。

- 界面元素选择器与设计稿还原归入「提效」，源码项目归入「研究」；3D 页面以「AI」中的「AI 向导 · 复杂交互」卡片呈现，介绍依据 100my-3dpage 的实际功能维护，保留技术栈、AI 对话/场景联动/飞行交互亮点与 page3d 源码入口，地址保持 HTTPS `/3D/`，不再提供顶部「新版3D」入口或资料卡片。
- 文档卡片通过 `kind: "skill"` 标识，与分类独立；NavGrid 据此在标题右侧显示 SKILL 徽标，左侧固定绿点；整卡进入图文介绍，不展示额外入口文字，并跳过服务在线检测。

- `subPages` 配置卡片头部小长条的目标地址与中英文名称，path 用作稳定键，不在界面显示。竞品工作台收录后台、队列监控、模型监控；生产分别为 `/Ai/admin/`、`/Ai/monitor/`、`/Ai/observability/`，本地沿用 109 项目的 18112 后台与 15555 Flower 入口。

- AI 向导卡片的「前端监控」指向 `/3D/monitor/`，本地预览使用已确认的线上 HTTPS 管理台地址。

- 外链配置不包含 requireOuterNet；浏览器直接处理访问。界面元素选择器介绍包含 DOM 选择、源码定位、Figma 转换与网页信息复制。
